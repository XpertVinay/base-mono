## 4. Standalone Web Frontend Enhancements

### 4.1 Typed API Client Services
Implemented a modular architecture under `frontend/src/core/api/services/` with envelope unwrapping:
- `envelope.ts`: Handles microservices standard envelope (`{ success, data, code, furtherSteps }`) and standardizes client error exceptions (`ApiServiceError`).
- **Domain Services**:
  - `organizationsApi`: Organization lifecycle and membership CRUD.
  - `rbacApi`: Roles, permissions, category indexing, role permissions, and role assignment.
  - `ordersApi`: Creation, querying, status transitions, cancellation.
  - `inventoryApi`: Stock queries, intake, reservations, and item management.
  - `assetsApi`: Asset metadata upload, filtering, removal.
  - `transactionsApi`: Gateway payment initiation, manual entry, status adjustments.
  - `configApi`: Dynamic key-value configuration, modular configuration sections.
  - `notificationsApi`: Direct dispatch, batch dispatch, delivery logs.
  - `schedulerApi`: Recurring cron task registration, triggers, deletion.
  - `recordsApi`: Entity record CRUD operations with multi-tenant headers.

  - Integrated `recordsApi.create`, `recordsApi.update`, and `recordsApi.delete`.

  - Added `initialData` prop and dynamic modal title (`Edit Record` vs `Add Record`).

## 5. CI/CD Pipeline Hardening (`RAG-agent`)

File: `RAG-agent/.github/workflows/deploy.yml`
- **SSH Key Validation Gate**:
  - Detects and rejects accidental PUBLIC key inputs (starting with `ssh-rsa`, `ssh-ed25519`, `ecdsa-sha2`).
  - Verifies presence of standard PEM/OpenSSH private key headers (`-----BEGIN`).
- **Flexible Secret Resolution**:
  - Resolves `TARGET_HOST` and `TARGET_KEY` across `vars` and multiple secret aliases (`VPS_HOST`, `SERVER_HOST`, `PROD_SERVER_HOST`, `STAGING_SERVER_HOST`).
  - Added support for `passphrase` (`VPS_SSH_PASSPHRASE`) and `password` authentication fallback.
